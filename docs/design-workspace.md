# Optional design and package workspace

Owners can text REDESIGN, ASSETS or PACKAGE after a measured report. ro_studio uses the current conversation's scoped run and sends an expiring owner link only to the owner chat verified by Plow. It does not send keys through the model or generate images by SMS. Guests cannot call this tool; owner checks apply in both the tool factory and existing access hook.

The hosted workspace requires the updated Sitemaxxing website with /api/studio/projects. REPORT_URL and REPORT_KEY keep their existing meanings. PLOW_AGENT_TOKEN is sent to that configured trusted website for identity verification against api.plow.co and is not saved there. Never configure REPORT_URL to an untrusted service. Owner session links are private; the generated package's viewing link is the shareable artifact.

Image generation uses the owner's website-connected provider and explicit per-request approval with an attempt allowance. Standard audits and report-only packages require no image-generation provider. Credit purchases and Latch image generation are not part of this release. The existing send-to-Mac fix-list command remains available.

When the previous PDF is too large for the hosted upload limit, workspace creation fails clearly and starts no paid work. Repeating a command resumes that report's existing project and issues a fresh 15-minute owner link. New reports create separate projects. Generated concepts do not count as measured findings or a working implementation.
